About me

Manu to most people. I've spent eight years running Meta and Google ad accounts, over €1.3M in spend, and I build the software I work with. I live in Utrecht and work remotely.

Why I do this

Nine years ago I had a dropshipping store and paid an agency around €4,000, fee plus ad spend, to run the ads. It brought in zero sales.

I couldn't accept spending that much and not getting a single sale. So I learned to run the ads myself, and that has been the job ever since.

One rule came out of it: everything I try, I try on myself first. If it costs money, it costs mine, never a client's.

What it turned into

For a while that work went by the name Ecomm GrowthLab. Today it is Climent Media, my company.

In 2025 I spent over €10,000 on ads-management platforms, looking for something that would actually read an account. They repeated what Google and Meta already say, with the same generic rules for everybody. So I built my own: a knowledge base per account, not a rule that fires the same way for everyone.

Today I run Google Ads and Meta Ads accounts myself, and the software I built reads each one every day.

I write down what I learn running accounts. The guide people read most is Google Ads change history: who changed what.
